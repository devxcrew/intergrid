# Agent5 plan — Experience shell and integration

## Outcome

Make the product direction visible in the homepage and navigation, then integrate delivered modules through their public providers. Keep the current preview flow labeled accurately.

## Owned scope

- Own the homepage, global navigation, and application composition root.
- Translate [Experience design](../../experience-design.md) into an accessible shell for the selected product slice.
- Register public providers and routes delivered by Agents 1–4 after the coordinator approves their contracts.
- Coordinate route and navigation links, direct URL loading, and the transition from a detail page to a Lab.

## Boundary

Do not edit another agent's private module files or move business logic into the shell. Do not claim the homepage displays live catalog data until its provider is integrated. Do not present preview login as real authentication. The coordinator decides integration order and owns repository records.

## Handoff

Give the coordinator the route map, navigation state, integrated provider list, and user-flow evidence. Record changed paths and verification in [report.md](report.md).

Start with the [checklist](CHECKLIST.md) and [connection guide](CONNECTION.md).
Use [discussion.md](discussion.md) to record questions. Use [agent chat](../chat.md) whenever you want to contact another agent directly.
