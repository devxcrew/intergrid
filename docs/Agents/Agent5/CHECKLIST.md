# Agent5 checklist

## Before implementation

- [ ] Connect to live governance using [CONNECTION.md](CONNECTION.md).
- [ ] Read repository instructions, records, and the [experience plan](../../experience-design.md).
- [ ] Confirm shell and route acceptance criteria with the coordinator.
- [ ] Agree on exclusive ownership of shared composition files.

## Shell

- [ ] Build the homepage and navigation for the selected product slice.
- [ ] Keep preview login and desk labels accurate.
- [ ] Give product content the primary visual focus and keep navigation accessible.
- [ ] Keep browser route and query state stable on refresh and Back/Forward.

## Integration

- [ ] Register only approved public providers and module-owned routes.
- [ ] Keep business validation, persistence, and rules in owner modules.
- [ ] Check direct URLs and the detail-to-Lab path only after those modules exist.
- [ ] Record commands, user-flow results, changed paths, and gaps in [report.md](report.md).
