# Experience design

## Visual direction

Intergrid should feel like a design instrument. The source masterplan names Apple, Linear, and Stripe as visual references. Its proposed principles are an obsidian and white foundation, editorial typography, ample space, fine borders, subtle glass, soft depth, restrained color, cinematic transitions, and fluid interaction.

The interface should give the featured design most of the visual attention. Motion should help a person inspect or edit the work.

## Homepage narrative

The proposed lead message is:

> INTERFACES WORTH BUILDING FROM.

Supporting copy explains the loop: explore exceptional interfaces, open them, inspect their parts, remix them, and build something new. The primary actions are **Explore Library** and **Open Labs**.

The proposed homepage sections follow this order:

1. Featured interfaces on large visual canvases.
2. Explore the Grid: components, sections, Experiences, interactions, systems, and Labs.
3. Built to be edited: a live transformation from original to customized remix.
4. Enter the Lab: an editor showcase.
5. The Grid keeps growing: community work and contributions.

## Core user journey

```text
Discover → Open an interface → Inspect → Open in Lab → Edit
         → Remix → Save → Publish → Discover again
```

Each surface should make the next action clear. The detail page leads into the Lab. The Lab leads to a saved remix. Publishing makes that remix available for discovery and reuse.
