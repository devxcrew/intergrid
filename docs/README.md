# Intergrid masterplan

> The editable library for exceptional interfaces.

Intergrid is a reusable interface library and an editable experimentation platform. People discover work, inspect its construction, edit it in a Lab, remix it, and turn it into reusable systems.

**Product loop:** Discover → Inspect → Edit → Remix → Build → Publish → Reuse.

Most documents describe the proposed product. Test 1 now provides a local preview of Asset discovery and inspection. See the [Test 1 proof](TEST-1-PROOF.md) and [repository README](../README.md) for current behavior and limits.

## Product boundary

The source masterplan describes a long-term direction. The first scoped Asset discovery and inspection flow passed in the local preview. The rest of the roadmap still needs separate acceptance criteria and verification.
